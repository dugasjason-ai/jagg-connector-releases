# JAGG Connector Releases

This repository distributes the **JAGG Connector** desktop installer for JAGG beta users.

It intentionally contains no application source code, business logic, or client/project data. Only the compiled installer, its SHA-256 checksum, and generic version/release notes are published here. The JAGG Connector's source code lives in a separate, private repository.

## Download

Get the latest installer from the [Releases](../../releases) page, or use the stable link:

`https://github.com/dugasjason-ai/jagg-connector-releases/releases/download/connector-latest/JAGG-Connector-Setup.exe`

Always verify the SHA-256 checksum listed on the release page before running the installer.

## What this repo is not

This is a binary distribution point only -- not a place for issues, discussion, or source contributions related to the JAGG product itself.
